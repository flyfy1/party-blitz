UNDER THE HOOD

Phones → Supabase → Big screen. No game server.

📱 120 phones

  • Postgres RPCs over HTTP
  • Listen to one Realtime Broadcast channel
  • Never publish, never see each other

⚡ Supabase

  • RLS on · security-definer RPCs only
  • Advisory lock → hard 120 cap
  • Server-side names · anti-cheat caps

🖥️ Big screen

  • The only referee
  • Scoring in unit-tested pure TypeScript
  • 2 broadcasts / round = 1/6 of Free tierwe read the rate-limiter source: 60-s rolling average
